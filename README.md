An interactive, high-performance digital study portal engineered for BCA 5th Semester students under **Chhatrapati Shahu Ji Maharaj University (CSJMU, Kanpur)**. Features comprehensive syllabus coverage across 19 modules, handwritten numerical methods step-by-step solutions, 3D interactive computer graphics models, and topic-wise question banks.

---

## 📚 Subject Curricula Covered

### 1. BCA-5001: Knowledge Management
- **Unit 1**: Business Intelligence & Strategic Decision Frameworks
- **Unit 2**: Executive Information Systems (EIS) & Data Warehousing
- **Unit 3**: Data Mining Techniques & Association Rules
- **Unit 4**: Knowledge Management Architecture & Systems

### 2. BCA-5002: Java Programming & Advanced Concepts
- **Unit 1**: Core Java OOP Principles, Multithreading & Exception Handling
- **Unit 2**: Abstract Window Toolkit (AWT), Event Handling & Applet Architecture
- **Unit 3**: JDBC (Java Database Connectivity) Drivers & Transactions
- **Unit 4**: Java Servlets Lifecycle, Session Management & Filters
- **Unit 5**: JavaServer Pages (JSP) Scriptlets, Directives & JavaBeans

### 3. BCA-5003: Computer Networks
- **Unit 1**: OSI 7-Layer Reference Model vs. TCP/IP Protocol Suite
- **Unit 2**: Physical Transmission Media, Guided & Wireless Transmission
- **Unit 3**: Data Link Layer, Flow Control (Sliding Window), Error Detection (CRC)
- **Unit 4**: Network Routing Algorithms, Subnetting & IP Addressing
- **Unit 5**: Transport Layer (TCP 3-Way Handshake, UDP) & Application Layer (DNS, HTTP)

### 4. BCA-5004: Numerical Methods
- **Unit 1**: Solution of Algebraic & Transcendental Equations (Bisection, Regula-Falsi, Newton-Raphson)
- **Unit 2**: Interpolation & Polynomial Approximation (Newton Forward/Backward, Lagrange)
- **Unit 3**: Numerical Differentiation & Integration (Trapezoidal, Simpson's 1/3 and 3/8 Rules)
- **Unit 4**: Numerical Solution of Ordinary Differential Equations (Euler's, Runge-Kutta 4th Order)

---

## ⚡ Tech Stack & Architecture

- **Frontend**: Next.js, React, Tailwind CSS, Lucide Icons
- **3D Interactive Visualizations**: Three.js / WebGL canvas rendering
- **Backend Services**: Python FastAPI / WSGI proxy server
- **Deployment**: Zero-downtime edge distribution on Vercel CDN
