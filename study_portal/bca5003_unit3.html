Unit III: Switching, Multiplexing & Flow Control

⚡ Essential Protocol Window & Efficiency Formulae
1. Stop-and-Wait ARQ Efficiency:
$$\eta = \frac{T_t}{T_t + 2T_p} = \frac{1}{1 + 2a} \quad \text{where } a = \frac{T_p}{T_t} = \frac{\text{Propagation Time}}{\text{Transmission Time}}$$
2. Window Sizes for Sequence Number bits ($m$):
• Go-Back-N ARQ: Sender Window $W_s = 2^m - 1$, Receiver Window $W_r = 1$
• Selective Repeat ARQ: Sender Window $W_s = 2^{m-1}$, Receiver Window $W_r = 2^{m-1}$
3. ISDN Interface Standards:
• BRI (Basic Rate Interface): $2B + D = 2(64) + 16 = \mathbf{144 \text{ kbps}}$
• PRI (Primary Rate - US): $23B + D = 23(64) + 64 = \mathbf{1.544 \text{ Mbps}}$
• PRI (Primary Rate - Europe): $30B + 2D = \mathbf{2.048 \text{ Mbps}}$
1. Go-Back-N vs Selective Repeat ARQ
⭐ CSJMU PYQs: 2025–26, 2023–24, 2021 (Comparison & Retransmission strategy)
Feature Go-Back-N ARQ Selective Repeat ARQ
Sender Window Size ($W_s$) $2^m - 1$ $2^{m-1}$
Receiver Window Size ($W_r$) Strictly 1 $2^{m-1}$
Out-of-Order Frames Discarded immediately Buffered and sorted
Retransmission Retransmits ALL frames from the lost frame onwards (Goes back $N$) Retransmits ONLY the specific damaged frame (Selective)
Acknowledgment Cumulative ACK (ACK $n$ confirms all frames up to $n-1$) Individual ACK / NAK for each frame
Bandwidth Efficiency Lower on error-prone channels Much Higher
What is Piggybacking?
In two-way (full-duplex) communication, instead of sending a dedicated control frame for ACK, the receiver delays the ACK and attaches (piggybacks) it onto its next outgoing data frame. This dramatically saves network bandwidth!

3. Multiplexing: FDM vs TDM vs WDM
⭐ CSJMU PYQs: 2022–23, 2021, 2018, 2017 (Combine multiple signals over one medium)
  • FDM (Frequency Division Multiplexing): Analog technique where channel bandwidth is divided into discrete frequency slots separated by guard bands to prevent crosstalk (Used in FM radio, Cable TV).
  • TDM (Time Division Multiplexing): Digital technique where entire bandwidth is assigned to each user for a specific repeating time slot. Synchronous TDM assigns fixed slots; Statistical TDM assigns dynamically based on demand.
  • WDM (Wavelength Division Multiplexing): Analog optical technique used in fiber optics where different data streams are modulated onto different wavelengths (colors) of laser light and transmitted simultaneously through a single fiber.
4. Congestion Control: Leaky Bucket vs Token Bucket
⭐ CSJMU PYQs: 2025–26, 2024–25, 2023–24 (Traffic Shaping algorithms)
Parameter Leaky Bucket Algorithm Token Bucket Algorithm
Output Rate Rigid constant rate regardless of input burst Can transmit at bursty rate if tokens are available
Action on Overflow Discards excess packets when bucket is full Discards excess tokens (packets wait or are transmitted)
Bursty Traffic Handling Completely smooths bursts (No burst transmission) Allows controlled bursts up to token capacity
