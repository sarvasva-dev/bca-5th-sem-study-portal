Unit III: Numerical Differentiation & Integration

Derivatives from difference tables, General Quadrature Formula, Trapezoidal Rule, Simpson's 1/3 Rule, Simpson's 3/8 Rule, and Truncation Errors.

⚡ Essential Quadrature Formula Sheet
1. Trapezoidal Rule (Linear Approximation, any $n$):
$$I = \int_a^b f(x) dx \approx \frac{h}{2} \left[ (y_0 + y_n) + 2(y_1 + y_2 + \dots + y_{n-1}) \right]$$ Global Truncation Error: $O(h^2) = -\frac{(b-a)h^2}{12} f''(\xi)$
2. Simpson's 1/3 Rule (Parabolic, requires EVEN $n$):
$$I \approx \frac{h}{3} \left[ (y_0 + y_n) + 4(y_1 + y_3 + \dots) + 2(y_2 + y_4 + \dots) \right]$$ Short form: $\frac{h}{3} \left[ \text{Ends} + 4(\text{Odd}) + 2(\text{Even}) \right]$. Error: $O(h^4)$
3. Simpson's 3/8 Rule (Cubic, requires $n$ multiple of 3):
$$I \approx \frac{3h}{8} \left[ (y_0 + y_n) + 3(y_1 + y_2 + y_4 + y_5 + \dots) + 2(y_3 + y_6 + \dots) \right]$$
📊 Visual Model: Trapezoidal vs Simpson's 1/3

Trapezoidal rule connects adjacent points with straight chords (linear). Simpson's 1/3 rule connects 3 points at a time with a parabolic curve, yielding higher accuracy ($O(h^4)$).

Numerical Integration: Area under curve sliced into $n$ strips of width $h$
1. Numerical Differentiation from Tables
⭐ CSJMU PYQs: 2025–26, 2024–25, 2021 (Find derivative at $x_0$ or interior point)

When an analytic equation is unavailable and only discrete tabulated data is given, derivatives are computed by differentiating the Newton interpolation polynomial.

Derivative at Beginning of Table ($x = x_0$):
$$f'(x_0) = \frac{1}{h} \left[ \Delta y_0 - \frac{1}{2}\Delta^2 y_0 + \frac{1}{3}\Delta^3 y_0 - \frac{1}{4}\Delta^4 y_0 + \dots \right]$$ $$f''(x_0) = \frac{1}{h^2} \left[ \Delta^2 y_0 - \Delta^3 y_0 + \frac{11}{12}\Delta^4 y_0 - \dots \right]$$
Derivative at End of Table ($x = x_n$):
$$f'(x_n) = \frac{1}{h} \left[ \nabla y_n + \frac{1}{2}\nabla^2 y_n + \frac{1}{3}\nabla^3 y_n + \frac{1}{4}\nabla^4 y_n + \dots \right]$$
2. Solved Master PYQ: $\int_0^1 \frac{dx}{1+x^2}$ (Value of $\pi$)
⭐ CSJMU PYQs: 2025–26, 2024–25, 2023–24 (The most famous university exam question!)

Problem: Evaluate $I = \int_0^1 \frac{1}{1+x^2} dx$ using (a) Trapezoidal Rule and (b) Simpson's 1/3 Rule taking $n = 6$. Hence deduce the approximate value of $\pi$.

📝 Step 1: Construct the Function Table ($h = \frac{1-0}{6} = \frac{1}{6}$)
$i$ $x_i$ $y_i = \frac{1}{1+x_i^2}$ Type
0 $0$ $1.00000$ End ($y_0$)
1 $1/6 \approx 0.1667$ $\frac{36}{37} \approx 0.97297$ Odd
2 $2/6 \approx 0.3333$ $\frac{9}{10} = 0.90000$ Even
3 $3/6 = 0.5$ $\frac{4}{5} = 0.80000$ Odd
4 $4/6 \approx 0.6667$ $\frac{9}{13} \approx 0.69231$ Even
5 $5/6 \approx 0.8333$ $\frac{36}{61} \approx 0.59016$ Odd
6 $1$ $\frac{1}{2} = 0.50000$ End ($y_6$)
📝 Step 2: Evaluation by Trapezoidal Rule

$\text{Sum of Ends} = y_0 + y_6 = 1.00000 + 0.50000 = \mathbf{1.50000}$

$\text{Sum of Remaining} = y_1 + y_2 + y_3 + y_4 + y_5 = 0.97297 + 0.90000 + 0.80000 + 0.69231 + 0.59016 = \mathbf{3.95544}$

$$I_{\text{Trap}} = \frac{h}{2} [ (y_0 + y_6) + 2(\text{Remaining}) ] = \frac{1/6}{2} [ 1.50000 + 2(3.95544) ] = \frac{1}{12} [ 9.41088 ] = \mathbf{0.78424}$$

Since $\int_0^1 \frac{dx}{1+x^2} = [\tan^{-1} x]_0^1 = \frac{\pi}{4}$:

$$\frac{\pi}{4} \approx 0.78424 \implies \pi \approx 4 \times 0.78424 = \mathbf{3.13696}$$

📝 Step 3: Evaluation by Simpson's 1/3 Rule

$\text{Sum of Ends} = y_0 + y_6 = 1.50000$

$\text{Sum of Odds} = y_1 + y_3 + y_5 = 0.97297 + 0.80000 + 0.59016 = \mathbf{2.36313}$

$\text{Sum of Evens} = y_2 + y_4 = 0.90000 + 0.69231 = \mathbf{1.59231}$

$$I_{\text{Simp}} = \frac{h}{3} [ (y_0 + y_6) + 4(\text{Odds}) + 2(\text{Evens}) ] = \frac{1/6}{3} [ 1.50000 + 4(2.36313) + 2(1.59231) ]$$ $$I_{\text{Simp}} = \frac{1}{18} [ 1.50000 + 9.45252 + 3.18462 ] = \frac{14.13714}{18} = \mathbf{0.78540}$$

$$\frac{\pi}{4} \approx 0.78540 \implies \pi \approx 4 \times 0.78540 = \mathbf{3.1416}$$ (Extremely accurate to 4 decimal places!)

3. Truncation vs Round-Off Errors

Truncation Error: Caused by truncating an infinite Taylor series to a finite number of terms. Reducing step size $h$ reduces truncation error (e.g., $O(h^2) \to 0$ as $h \to 0$).

Round-Off Error: Caused by finite numerical storage and division in machines. Decreasing $h$ too much increases round-off errors because nearly identical numbers are subtracted. The optimal step size $h^*$ balances both.
