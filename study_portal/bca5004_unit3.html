1. Numerical Differentiation Formulas
🎯 Learning Objectives:
  • Approximate derivatives $f'(x)$ and $f''(x)$ when only tabular data is known.
  • Derive first and second derivative formulas from Newton's forward difference series.
⚡ Essential Pass Content
First Derivative at Starting Point $x_0$:
$$f'(x_0) = \left( \frac{dy}{dx} \right)_{x=x_0} = \frac{1}{h} \left[ \Delta y_0 - \frac{1}{2} \Delta^2 y_0 + \frac{1}{3} \Delta^3 y_0 - \frac{1}{4} \Delta^4 y_0 + \dots \right]$$ Second Derivative at Starting Point $x_0$:
$$f''(x_0) = \left( \frac{d^2 y}{dx^2} \right)_{x=x_0} = \frac{1}{h^2} \left[ \Delta^2 y_0 - \Delta^3 y_0 + \frac{11}{12} \Delta^4 y_0 - \dots \right]$$
2. Numerical Integration: The 3 Core Rules
⭐ CSJMU PYQs: 2025–26, 2024–25, 2022, 2020, 2018 (Simpson's rules vs Trapezoidal rule and comparative accuracy)

Numerical integration (quadrature) calculates $\int_a^b f(x) dx$ when $f(x)$ is difficult to integrate analytically or given as discrete table values. Divide $[a, b]$ into $n$ equal sub-intervals of width $h = \frac{b - a}{n}$.

⚡ Essential Pass Content
1. Trapezoidal Rule ($n$ can be ANY positive integer):
$$\int_a^b y \, dx = \frac{h}{2} \Big[ (y_0 + y_n) + 2(y_1 + y_2 + \dots + y_{n-1}) \Big]$$ Structure: $\frac{h}{2} [\text{First} + \text{Last} + 2(\text{Sum of all others})]$. Degree of Precision = $1$. Error $= O(h^2)$.
2. Simpson's 1/3 Rule (MANDATORY: $n$ must be an EVEN integer):
$$\int_a^b y \, dx = \frac{h}{3} \Big[ (y_0 + y_n) + 4(y_1 + y_3 + y_5 + \dots) + 2(y_2 + y_4 + y_6 + \dots) \Big]$$ Structure: $\frac{h}{3} [\text{Ends} + 4(\text{Odd Ordinates}) + 2(\text{Even Ordinates})]$. Degree of Precision = $3$. Error $= O(h^4)$.
3. Simpson's 3/8 Rule (MANDATORY: $n$ must be a MULTIPLE OF 3):
$$\int_a^b y \, dx = \frac{3h}{8} \Big[ (y_0 + y_n) + 3(y_1 + y_2 + y_4 + y_5 + \dots) + 2(y_3 + y_6 + y_9 + \dots) \Big]$$ Structure: $\frac{3h}{8} [\text{Ends} + 3(\text{Non-multiples of 3}) + 2(\text{Multiples of 3})]$. Degree of Precision = $3$. Error $= O(h^4)$.
📚 Full Understanding Track: Derivation of the Quadrature Formula
General Newton-Cotes Quadrature Derivation:
Substituting Newton's forward interpolation into $\int_{x_0}^{x_0 + nh} y dx$ with $x = x_0 + uh$ ($dx = h du$): $$\int_{x_0}^{x_0+nh} y dx = h \int_0^n \left[ y_0 + u \Delta y_0 + \frac{u^2-u}{2} \Delta^2 y_0 + \frac{u^3-3u^2+2u}{6} \Delta^3 y_0 + \dots \right] du$$ Integrating term by term yields the Master Quadrature Equation: $$\int_{x_0}^{x_n} y dx = nh \left[ y_0 + \frac{n}{2} \Delta y_0 + \frac{n(2n-3)}{12} \Delta^2 y_0 + \frac{n(n-1)^2}{24} \Delta^3 y_0 + \dots \right]$$
  • Setting $n = 1$ and neglecting 2nd order differences yields the Trapezoidal Rule.
  • Setting $n = 2$ and neglecting 3rd order differences yields Simpson's 1/3 Rule.
  • Setting $n = 3$ and neglecting 4th order differences yields Simpson's 3/8 Rule.
3. Master Solved University Numerical (All 3 Rules Compared)
⭐ CSJMU Exam Classic: Evaluate $\int_0^6 \frac{dx}{1 + x^2}$ by (i) Trapezoidal, (ii) Simpson's 1/3, and (iii) Simpson's 3/8 Rules with $h = 1$.

Limits: $a = 0, b = 6$. Step size $h = 1 \implies n = \frac{6 - 0}{1} = 6$ sub-intervals.
Check: $n = 6$ is both an even number (valid for Simpson's 1/3) and a multiple of 3 (valid for Simpson's 3/8)!

$i$ $x_i$ $y_i = \frac{1}{1 + x_i^2}$ Exact Decimal Value Role in Formulas
0 0 $1 / (1 + 0) = 1$ 1.00000 $y_0$ (End)
1 1 $1 / (1 + 1) = 1/2$ 0.50000 $y_1$ (Odd)
2 2 $1 / (1 + 4) = 1/5$ 0.20000 $y_2$ (Even)
3 3 $1 / (1 + 9) = 1/10$ 0.10000 $y_3$ (Odd & Multiple of 3)
4 4 $1 / (1 + 16) = 1/17$ 0.05882 $y_4$ (Even)
5 5 $1 / (1 + 25) = 1/26$ 0.03846 $y_5$ (Odd)
6 6 $1 / (1 + 36) = 1/37$ 0.02703 $y_6$ (End)

Sub-Sums:
Ends: $y_0 + y_6 = 1.00000 + 0.02703 = \mathbf{1.02703}$
Odds ($y_1 + y_3 + y_5$): $0.50000 + 0.10000 + 0.03846 = \mathbf{0.63846}$
Evens ($y_2 + y_4$): $0.20000 + 0.05882 = \mathbf{0.25882}$
All intermediates: $0.63846 + 0.25882 = \mathbf{0.89728}$

(i) By Trapezoidal Rule:
$$I_T = \frac{1}{2} \Big[ (y_0 + y_6) + 2(y_1 + y_2 + y_3 + y_4 + y_5) \Big]$$ $$I_T = 0.5 \times [1.02703 + 2(0.89728)] = 0.5 \times [1.02703 + 1.79456] = 0.5 \times 2.82159 = \mathbf{1.4108}$$
(ii) By Simpson's 1/3 Rule:
$$I_{S1/3} = \frac{1}{3} \Big[ (y_0 + y_6) + 4(y_1 + y_3 + y_5) + 2(y_2 + y_4) \Big]$$ $$I_{S1/3} = \frac{1}{3} [1.02703 + 4(0.63846) + 2(0.25882)] = \frac{1}{3} [1.02703 + 2.55384 + 0.51764] = \frac{4.09851}{3} = \mathbf{1.3662}$$
(iii) By Simpson's 3/8 Rule:
$$I_{S3/8} = \frac{3(1)}{8} \Big[ (y_0 + y_6) + 3(y_1 + y_2 + y_4 + y_5) + 2(y_3) \Big]$$ Non-multiples of 3: $y_1 + y_2 + y_4 + y_5 = 0.50000 + 0.20000 + 0.05882 + 0.03846 = 0.79728$.
Multiple of 3: $y_3 = 0.10000$.
$$I_{S3/8} = \frac{3}{8} [1.02703 + 3(0.79728) + 2(0.10000)] = \frac{3}{8} [1.02703 + 2.39184 + 0.20000] = \frac{3}{8} [3.61887] = \mathbf{1.3571}$$
Comparison with Exact Analytical Solution:
$$\int_0^6 \frac{dx}{1 + x^2} = \Big[ \arctan(x) \Big]_0^6 = \arctan(6) - \arctan(0) \approx 1.4056 \text{ radians}$$ Trapezoidal error: $|1.4108 - 1.4056| = 0.0052$. Both Simpson rules achieve high accuracy with low computational overhead.
