💡 Conceptual Intuition: Why Did Java Introduce AWT and Applets?
In the mid-1990s, web pages were completely static: plain HTML documents containing black text and blue hyperlinks. There was no JavaScript, no CSS animations, and no video players.
Java revolutionized the World Wide Web by introducing **Applets**: small compiled Java bytecode programs downloaded automatically by the browser and executed inside the client's local JVM. To give these applets buttons, textfields, checkboxes, and graphics, Sun Microsystems created the **Abstract Window Toolkit (AWT)**!
1. Abstract Window Toolkit (AWT) Class Hierarchy
⭐ CSJMU PYQs: 2024–25, 2022–23, 2018 (Define AWT, draw component hierarchy, explain controls)

The Abstract Window Toolkit (AWT) is Java's original package (java.awt) for developing Graphical User Interfaces (GUIs). AWT components are **heavyweight** because each component is backed by an underlying native operating system peer.

2. Layout Managers in AWT
⭐ CSJMU PYQs: 2024–25, 2023–24, 2021 (Compare FlowLayout, BorderLayout, and GridLayout)

A Layout Manager is an object that implements the LayoutManager interface and automatically determines the position and dimensions of components within a Container, ensuring responsive GUI layouts across different screen sizes and operating systems.

Layout Manager Default For Arrangement Behavior Constructor / Syntax
FlowLayout Panel and Applet Arranges components sequentially in a line (left-to-right). When a line fills up, components wrap to the next line. setLayout(new FlowLayout(FlowLayout.CENTER, 10, 10));
BorderLayout Frame and Window Divides the container into 5 geographic regions: NORTH, SOUTH, EAST, WEST, and CENTER. Center expands to fill remaining space. add(b1, BorderLayout.NORTH); add(b2, BorderLayout.CENTER);
GridLayout Manual assignment Divides the container into a rectangular grid of equal-sized rows and columns. Every cell has identical width and height. setLayout(new GridLayout(3, 2, 5, 5)); // 3 rows, 2 cols
CardLayout Manual assignment Treats each component as a card in a deck, displaying only one card at a time. Ideal for wizard step screens. cardLayout.show(container, "cardName");
GridBagLayout Manual assignment Most flexible and powerful layout manager; components can span multiple rows and columns with varying sizes using GridBagConstraints. setLayout(new GridBagLayout());
3. The Delegation Event Model & Event Handling
⭐ CSJMU PYQs: 2025–26, 2023–24, 2022–23 (Explain Delegation Event Model, Sources, Listeners, and Adapter Classes)

Java handles user interactions (button clicks, keystrokes, mouse moves) using the modern Delegation Event Model introduced in Java 1.1. In this model, the control that receives the user input **delegates** processing to registered listener objects.

The 3 Participants in the Delegation Event Model:
  1. Event Source: The GUI component that generates the event when the user interacts with it (e.g. Button, TextField).
  2. Event Object: Encapsulates all state information about the event (inherits from java.util.EventObject, e.g. ActionEvent, MouseEvent).
  3. Event Listener: An object implementing a specific listener interface that receives and handles the notification (e.g. ActionListener).
Event Class Generated By Corresponding Listener Key Handler Method(s)
ActionEvent Button click, Enter key in TextField, Menu item select ActionListener actionPerformed(ActionEvent e)
MouseEvent Mouse clicked, pressed, released, moved, dragged MouseListener, MouseMotionListener mouseClicked(), mousePressed(), mouseMoved()
KeyEvent Key pressed, released, typed KeyListener keyPressed(), keyReleased(), keyTyped()
WindowEvent Window opened, closed, closing, minimized WindowListener windowClosing(), windowOpened()

Why Do We Need Adapter Classes?

In Java, when a class implements an interface, it is required to provide concrete implementations for every single method declared in that interface. For example, WindowListener declares 7 methods! Even if you only care about closing the window (windowClosing()), you would have to write 6 empty dummy methods!

Solution: Adapter Classes: Java provides abstract adapter classes (such as WindowAdapter, MouseAdapter, KeyAdapter) that provide empty default implementations for all listener methods. You can simply subclass the adapter and override only the single method you need!

// Using WindowAdapter with an Anonymous Inner Class to close a Frame:
frame.addWindowListener(new WindowAdapter() {
    public void windowClosing(WindowEvent e) {
        System.exit(0); // Gracefully close application
    }
});

Master Exam Code: Complete Runnable AWT GUI Application

Problem (CSJMU 2024–25 & Lab Q14): Write a complete Java AWT program to create a User Registration Form with Labels, TextFields, Radio Buttons (CheckboxGroup), Dropdown Choice, and a Submit Button that handles the click event:

import java.awt.*;
import java.awt.event.*;

public class StudentForm extends Frame implements ActionListener {
    Label lblTitle, lblName, lblGender, lblCity, lblResult;
    TextField tfName;
    CheckboxGroup cbg;
    Checkbox rbMale, rbFemale;
    Choice chCity;
    Button btnSubmit;

    public StudentForm() {
        // 1. Frame setup
        setTitle("Student Registration Portal");
        setSize(380, 360);
        setLayout(new FlowLayout(FlowLayout.CENTER, 15, 12));

        // 2. Instantiate controls
        lblTitle = new Label("--- Student Registration Form ---");
        lblTitle.setFont(new Font("Arial", Font.BOLD, 14));

        lblName = new Label("Full Name:");
        tfName = new TextField(22);

        lblGender = new Label("Gender:");
        cbg = new CheckboxGroup();
        rbMale = new Checkbox("Male", cbg, true);
        rbFemale = new Checkbox("Female", cbg, false);

        lblCity = new Label("Select City:");
        chCity = new Choice();
        chCity.add("Kanpur");
        chCity.add("Lucknow");
        chCity.add("Delhi");
        chCity.add("Varanasi");

        btnSubmit = new Button("Submit Application");
        lblResult = new Label("Status: Awaiting input...");

        // 3. Register Action Listener
        btnSubmit.addActionListener(this);

        // 4. Add controls to Frame
        add(lblTitle);
        add(lblName); add(tfName);
        add(lblGender); add(rbMale); add(rbFemale);
        add(lblCity); add(chCity);
        add(btnSubmit);
        add(lblResult);

        // 5. Close window via WindowAdapter
        addWindowListener(new WindowAdapter() {
            public void windowClosing(WindowEvent e) {
                dispose();
            }
        });

        setVisible(true);
    }

    // Event Handler Method
    public void actionPerformed(ActionEvent e) {
        String name = tfName.getText();
        String gender = cbg.getSelectedCheckbox().getLabel();
        String city = chCity.getSelectedItem();
        lblResult.setText("Registered: " + name + " (" + gender + ", " + city + ")");
    }

    public static void main(String[] args) {
        new StudentForm();
    }
}

4. Applet Fundamentals & The 5-Stage Lifecycle
⭐ CSJMU PYQs: 2025–26, 2024–25, 2023–24, 2022–23, 2020, 2017 (Super-high frequency 10-mark question!)

An Applet is a special type of Java program embedded in an HTML web page and executed on a client machine within a Java-enabled web browser or the SDK appletviewer. Every applet extends java.applet.Applet.

Complete 5-Stage Applet Lifecycle: init() → start() ⇄ stop() → destroy()
Method Signature Invoked By Lifecycle Stage & Responsibility
public void init() Browser / Appletviewer Initialization (Once): Invoked exactly once when the applet is first loaded into memory. Used to allocate memory, load images, and add AWT controls.
public void start() Browser Execution Start / Resume: Invoked immediately after init(), and called every time the user navigates back to the applet's tab. Used to start threads and animations.
public void paint(Graphics g) AWT Paint Subsystem Display / Redraw: Invoked whenever the applet's output needs refreshing (window restored, resized). Takes a Graphics object to render shapes and text.
public void stop() Browser Suspension: Invoked automatically whenever the user navigates away from the web page or minimizes the browser. Used to pause heavy background threads.
public void destroy() Browser Termination (Once): Invoked once before the applet is completely unloaded from RAM. Releases native operating system resources.

Complete Runnable Applet Example with HTML Embedding & Parameters:

// File: BannerApplet.java
import java.applet.Applet;
import java.awt.Graphics;
import java.awt.Color;
import java.awt.Font;

public class BannerApplet extends Applet {
    String msg;

    public void init() {
        setBackground(Color.DARK_GRAY);
        setForeground(Color.WHITE);
        // Read external parameter passed from HTML
        msg = getParameter("city");
        if (msg == null) msg = "Kanpur";
    }

    public void paint(Graphics g) {
        g.setFont(new Font("Arial", Font.BOLD, 18));
        g.drawString("Welcome to CSJMU: " + msg, 40, 60);
        g.drawRect(30, 30, 320, 50);
    }
}

Associated HTML File (BannerApplet.html):

<!-- HTML file to run the applet via appletviewer -->
<html>
  <body>
    <applet code="BannerApplet.class" width="400" height="150">
      <param name="city" value="Kanpur University" />
    </applet>
  </body>
</html>

How to Score Full 10 Marks on "Applet vs Application & Applet Lifecycle":

    ⚠️ Common Exam Pitfalls:
    • Writing main() inside an Applet: Applets DO NOT have a main() method! The browser/appletviewer acts as the container and invokes init() directly.
    • Confusing stop() and destroy(): stop() is temporary (invoked when switching tabs; can restart via start()); destroy() is final and unrecoverable.
