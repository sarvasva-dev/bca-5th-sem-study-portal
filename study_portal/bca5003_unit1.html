1. Data Communication Fundamentals
⭐ CSJMU PYQs: 2024–25, 2021, 2018, 2017 (5 Components & 4 Characteristics)
The 5 Core Components:
  1. Message: The data/information to be communicated (text, audio, video).
  2. Sender: The device that generates and transmits the message (computer, phone).
  3. Receiver: The target device that receives the message.
  4. Transmission Medium: The physical path connecting sender and receiver (twisted pair, fiber optic, radio waves).
  5. Protocol: A set of governing rules that coordinate data communication. Without a protocol, two devices may be connected but cannot communicate.
The 4 Fundamental Characteristics:
  • Delivery: System must deliver data to the correct intended destination only.
  • Accuracy: Data must be delivered accurately without alteration or corruption.
  • Timeliness: Data must arrive within an acceptable time frame (especially for real-time video/voice).
  • Jitter: The variation in packet arrival time. Low jitter ensures smooth multimedia playback without audio cracks.
2. Network Topologies Comparison
⭐ CSJMU PYQs: 2024–25, 2023–24, 2021, 2019 (Mesh vs Star vs Bus vs Ring)
Topology Cabling / Links Advantages Disadvantages
Mesh $\frac{n(n-1)}{2}$ links
($n-1$ ports/node)		 Dedicated links, no traffic congestion, robust (single failure does not affect others), high privacy Massive cable cost, complex installation, difficult maintenance
Star $n$ links (via central Hub/Switch) Easy to install, fault-isolated (if one node fails, others work), easy to reconfigure Single point of failure: If central Hub/Switch dies, entire network shuts down
Bus Single backbone cable with terminators Cheapest, minimal cabling required High collision probability, difficult troubleshooting, backbone break kills network
Ring $n$ point-to-point links (Token Ring) Orderly traffic flow (tokens), equal access for all nodes Unidirectional break can bring down entire ring (unless dual ring FDDI used)
3. Cyclic Redundancy Check (CRC) Solved PYQ
⭐ CSJMU PYQs: 2025–26, 2023–24, 2021 (CRC generation & verification numerical)

Method: Binary division using modulo-2 arithmetic (XOR operation, where $1 \oplus 1 = 0$, $0 \oplus 0 = 0$, $1 \oplus 0 = 1$).

📝 Solved Example: Generate CRC Code

Given Data: $M = 1010000$ (7 bits)
Generator Polynomial: $G(x) = x^3 + 1 \implies G = 1001$ (4 bits, degree $r = 3$).

Step 1: Append $r = 3$ zeros to Data: $M' = 1010000\mathbf{000}$ (10 bits).

Step 2: Modulo-2 Division of $1010000000$ by $1001$:

      1011100  (Quotient)
1001 | 1010000000
       1001
       ----
       001100
         1001
         ----
         01010
          1001
          ----
          001100
            1001
            ----
            0110  <-- Remainder (CRC = 011)

Step 3: Transmitted Codeword:
$\text{Codeword} = \text{Data} + \text{Remainder} = 1010000\mathbf{011}$.

Receiver Check: Receiver divides $1010000011$ by $1001$. Since remainder is $000$, data is error-free!

4. OSI vs TCP/IP Comparison
Feature OSI Reference Model TCP/IP Protocol Suite
Number of Layers 7 Layers 4 Layers (or 5 in modern mapping)
Approach Theoretical model developed by ISO Practical, implementation-first (ARPANET)
Session & Presentation Separate dedicated layers (5 & 6) Merged into the single Application Layer
Transport Layer Guaranteed connection-oriented service Supports both TCP (connection-oriented) & UDP (connectionless)
Usage Universal reference & educational model The real-world protocol of the Internet
