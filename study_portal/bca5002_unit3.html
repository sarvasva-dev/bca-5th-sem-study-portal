1. The 4 JDBC Driver Types
⭐ CSJMU PYQs: 2025–26, 2023–24, 2021, 2017 (Repeatedly asked for 10 marks: explain all 4 drivers with diagrams)
⚡ Essential Pass Content

JDBC (Java Database Connectivity) is a standardized Java API (in java.sql) that enables Java applications to connect to relational databases, execute SQL queries, and process tabular results.

Driver Type Name & Architecture How It Works Key Pros & Cons
Type 1 JDBC-ODBC Bridge Driver Translates JDBC calls to native ODBC calls; uses local C-based ODBC driver Easy initial setup; very slow, platform-dependent, deprecated in modern Java
Type 2 Native-API / Partly Java Driver Translates JDBC calls into client-side native database C/C++ library API calls (e.g. OCI for Oracle) Faster than Type 1; requires installing proprietary database client software on every client PC
Type 3 Network-Protocol / Middleware Driver All-Java client sends generic JDBC calls over sockets to an intermediate Middleware Server, which translates them for the target DB Very flexible; supports multi-database pooling; requires maintaining a separate middleware server
Type 4 Thin Driver / Direct Pure Java Driver 100% pure Java driver that speaks the database engine's proprietary network protocol directly over TCP/IP sockets Highest performance, zero client installation, platform independent; universally preferred standard!
2. The 5 Standard Steps of JDBC
⭐ CSJMU PYQs: 2024–25, 2022, 2019 (Write code to connect to database and retrieve records)
⚡ Essential Pass Content
The 5 Golden Steps to Memorize for Exams:
  1. Step 1: Load & Register the Driver:
    Class.forName("com.mysql.cj.jdbc.Driver");
  2. Step 2: Establish the Database Connection:
    Connection con = DriverManager.getConnection("jdbc:mysql://localhost:3306/college", "root", "password");
  3. Step 3: Create a Statement or PreparedStatement:
    PreparedStatement pstmt = con.prepareStatement("SELECT * FROM student WHERE id = ?");
  4. Step 4: Execute the SQL Query:
    pstmt.setInt(1, 101);
    ResultSet rs = pstmt.executeQuery();
  5. Step 5: Process Results & Close Resources:
    while (rs.next()) { System.out.println(rs.getString("name")); }
    rs.close(); pstmt.close(); con.close();
Complete JDBC Example with PreparedStatement 
import java.sql.*;

public class JdbcSelectDemo {
    public static void main(String[] args) {
        String url = "jdbc:mysql://localhost:3306/university_db";
        String user = "root";
        String pass = "exam2026";
        String sql = "SELECT roll_no, name, marks FROM bca_students WHERE marks >= ?";

        // Try-with-resources automatically closes connection, statement, and resultset
        try (Connection con = DriverManager.getConnection(url, user, pass);
             PreparedStatement pstmt = con.prepareStatement(sql)) {

            pstmt.setDouble(1, 75.0); // Parameter binding prevents SQL Injection
            ResultSet rs = pstmt.executeQuery();

            System.out.println("Roll | Name | Marks");
            System.out.println("--------------------");
            while (rs.next()) {
                int roll = rs.getInt("roll_no");
                String name = rs.getString("name");
                double marks = rs.getDouble("marks");
                System.out.println(roll + " | " + name + " | " + marks);
            }
        } catch (SQLException e) {
            System.err.println("Database Error: " + e.getMessage());
        }
    }
}
3. Statement vs PreparedStatement
⭐ CSJMU PYQs: 2024–25, 2021 (Comparison & SQL Injection explanation)
⚡ Essential Pass Content
Feature Statement PreparedStatement
Precompilation Compiled by database engine on every execution Precompiled once by DB engine; can be executed repeatedly with different values
Performance Slower for repeated queries Significantly faster for batch updates and repeated executions
SQL Injection Security Vulnerable to SQL Injection attacks via string concatenation: "' OR '1'='1" Immune: Placeholders (?) treat user input strictly as literal values, never executable SQL
Syntax stmt.executeQuery("SELECT ... " + id) pstmt.setInt(1, id); pstmt.executeQuery();
