Unit V: Numerical Solution of ODEs

Initial Value Problems, Euler's Method, Modified Euler's Method, Picard's Successive Approximations, and Runge-Kutta 4th Order Method (RK4).

1. Initial Value Problems & Euler's Method
🎯 Learning Objectives:
  • Define an Initial Value Problem (IVP): $\frac{dy}{dx} = f(x, y)$ with condition $y(x_0) = y_0$.
  • Understand Euler's tangent step algorithm and its error limitations ($O(h)$ global error).
⚡ Essential Pass Content
Euler's Iteration Formula:
$$y_{n+1} = y_n + h \cdot f(x_n, y_n)$$ Condition: Step size $h = x_{n+1} - x_n$. Truncation error: Local $= O(h^2)$, Global $= O(h)$.

Geometric Principle: Euler's method approximates the solution curve by straight-line tangent segments across step size $h$. Because the tangent direction changes continuously, Euler's method drifts away from the true curve unless $h$ is very small.

2. Picard's Successive Approximations
⭐ CSJMU PYQs: 2024–25, 2022, 2018 (Derivation and 5–10 mark analytical integration question)
⚡ Essential Pass Content
Picard's Iterative Integral Formula:
$$y^{(k+1)}(x) = y_0 + \int_{x_0}^x f\Big(t, y^{(k)}(t)\Big) \, dt$$ where initial approximation $y^{(0)}(x) = y_0$ (constant).
📝 Solved University Numerical:
Problem: Given $\frac{dy}{dx} = x + y^2$ with $y(0) = 1$, find the first two successive approximations using Picard's method.
Initial Starting Values: $x_0 = 0, y_0 = 1$. Let $y^{(0)} = 1$.
First Approximation $y^{(1)}(x)$:
$$y^{(1)}(x) = 1 + \int_0^x \Big[ t + (y^{(0)})^2 \Big] dt = 1 + \int_0^x (t + 1^2) dt = 1 + \left[ \frac{t^2}{2} + t \right]_0^x = \mathbf{1 + x + \frac{x^2}{2}}$$
Second Approximation $y^{(2)}(x)$:
Substitute $y^{(1)} = 1 + x + \frac{x^2}{2}$ into $f(t, y) = t + y^2$ (neglecting powers $x^3$ and above if small):
$$(y^{(1)})^2 = \left(1 + x + \frac{x^2}{2}\right)^2 \approx 1 + 2x + 2x^2$$ $$y^{(2)}(x) = 1 + \int_0^x \Big[ t + (1 + 2t + 2t^2) \Big] dt = 1 + \int_0^x (1 + 3t + 2t^2) dt = \mathbf{1 + x + \frac{3x^2}{2} + \frac{2x^3}{3}}$$
3. Runge-Kutta 4th Order Method (RK4)
⭐ CSJMU PYQs: 2025–26, 2023–24, 2021, 2019, 2015 (Repeatedly asked for 10 marks — highest weightage!)
⚡ Essential Pass Content
The 4 Slopes & Increment Formula:
$$\begin{aligned} k_1 &= h \cdot f(x_0, y_0) \\ k_2 &= h \cdot f\left( x_0 + \frac{h}{2}, y_0 + \frac{k_1}{2} \right) \\ k_3 &= h \cdot f\left( x_0 + \frac{h}{2}, y_0 + \frac{k_2}{2} \right) \\ k_4 &= h \cdot f( x_0 + h, y_0 + k_3 ) \\ \Delta y &= \frac{1}{6} \Big( k_1 + 2k_2 + 2k_3 + k_4 \Big) \\ y(x_0 + h) &= y_0 + \Delta y \end{aligned}$$ Why RK4 is Supreme: It achieves fourth-order accuracy ($O(h^4)$ global error) matching Taylor series through $h^4$, without requiring any analytical differentiation!
📝 Master Solved University Problem:
Apply the Runge-Kutta 4th Order method to find $y(0.1)$ given: $$\frac{dy}{dx} = x + y, \quad y(0) = 1, \quad \text{with step size } h = 0.1$$

Step-by-Step Numerical Calculations:

Given Parameters:
$f(x, y) = x + y$, initial values $x_0 = 0, y_0 = 1$, step size $h = 0.1$.
Step 1: Calculate $k_1$:
$$k_1 = h \cdot f(x_0, y_0) = 0.1 \times (0 + 1) = \mathbf{0.10000}$$
Step 2: Calculate $k_2$:
$$x_0 + \frac{h}{2} = 0 + 0.05 = 0.05$$ $$y_0 + \frac{k_1}{2} = 1 + \frac{0.10000}{2} = 1.05$$ $$k_2 = h \cdot f(0.05, 1.05) = 0.1 \times (0.05 + 1.05) = 0.1 \times 1.10 = \mathbf{0.11000}$$
Step 3: Calculate $k_3$:
$$x_0 + \frac{h}{2} = 0.05$$ $$y_0 + \frac{k_2}{2} = 1 + \frac{0.11000}{2} = 1.055$$ $$k_3 = h \cdot f(0.05, 1.055) = 0.1 \times (0.05 + 1.055) = 0.1 \times 1.105 = \mathbf{0.11050}$$
Step 4: Calculate $k_4$:
$$x_0 + h = 0 + 0.1 = 0.1$$ $$y_0 + k_3 = 1 + 0.11050 = 1.11050$$ $$k_4 = h \cdot f(0.1, 1.11050) = 0.1 \times (0.1 + 1.11050) = 0.1 \times 1.21050 = \mathbf{0.12105}$$
Step 5: Weighted Average Increment $\Delta y$:
$$\Delta y = \frac{1}{6} \Big[ k_1 + 2k_2 + 2k_3 + k_4 \Big]$$ $$\Delta y = \frac{1}{6} \Big[ 0.10000 + 2(0.11000) + 2(0.11050) + 0.12105 \Big]$$ $$\Delta y = \frac{1}{6} \Big[ 0.10000 + 0.22000 + 0.22100 + 0.12105 \Big] = \frac{0.66205}{6} = \mathbf{0.11034}$$
Step 6: Compute Final Value $y(0.1)$:
$$y(0.1) = y_0 + \Delta y = 1 + 0.11034 = \mathbf{1.11034}$$ Exact Analytical Verification: Solution is $y = 2e^x - x - 1$. For $x = 0.1$: $y = 2(1.10517) - 0.1 - 1 = 1.11034$ (Error is less than $10^{-5}$!).
