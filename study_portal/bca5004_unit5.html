Unit V: Solution of Differential Equations

Initial Value Problems, Euler's Method, Picard's Successive Approximations, and Runge-Kutta 4th Order (RK-4) Method.

⚡ Essential ODE Formula Cheat Sheet
1. Euler's Method (Tangent line, $O(h)$ global error):
$$y_{n+1} = y_n + h f(x_n, y_n)$$
2. Picard's Method of Successive Approximations:
$$y^{(n+1)}(x) = y_0 + \int_{x_0}^x f(t, y^{(n)}(t)) dt$$
3. Runge-Kutta 4th Order (RK-4) Method ($O(h^4)$ global error):
$$k_1 = h f(x_n, y_n)$$ $$k_2 = h f\left(x_n + \frac{h}{2}, y_n + \frac{k_1}{2}\right)$$ $$k_3 = h f\left(x_n + \frac{h}{2}, y_n + \frac{k_2}{2}\right)$$ $$k_4 = h f\left(x_n + h, y_n + k_3\right)$$ $$y_{n+1} = y_n + \frac{1}{6} \left( k_1 + 2k_2 + 2k_3 + k_4 \right)$$
1. Runge-Kutta 4th Order (RK-4)
⭐ CSJMU PYQs: 2025–26, 2024–25, 2023–24, 2021 (The most repeated numerical in CSJMU!)

Why RK-4 is superior: Unlike Taylor series, RK-4 does NOT require computing higher-order analytical derivatives of $f(x,y)$. It achieves 4th-order accuracy ($O(h^4)$ global error) solely by evaluating $f(x,y)$ at four strategic points across the subinterval.

📝 Step-by-Step Solved Master PYQ: Solve $\frac{dy}{dx} = x + y$, $y(0)=1$ for $y(0.1)$

Given: $\frac{dy}{dx} = f(x, y) = x + y$, with initial condition $x_0 = 0, y_0 = 1$, and step size $h = 0.1$.

Step 1: Calculate $k_1$ (Slope at beginning):
$k_1 = h f(x_0, y_0) = 0.1 \times (0 + 1) = \mathbf{0.1000}$

Step 2: Calculate $k_2$ (Slope at midpoint using $k_1$):
$x_0 + \frac{h}{2} = 0 + 0.05 = 0.05$
$y_0 + \frac{k_1}{2} = 1 + \frac{0.1}{2} = 1.05$
$k_2 = h f(0.05, 1.05) = 0.1 \times (0.05 + 1.05) = 0.1 \times 1.10 = \mathbf{0.1100}$

Step 3: Calculate $k_3$ (Slope at midpoint using $k_2$):
$x_0 + \frac{h}{2} = 0.05$
$y_0 + \frac{k_2}{2} = 1 + \frac{0.11}{2} = 1.055$
$k_3 = h f(0.05, 1.055) = 0.1 \times (0.05 + 1.055) = 0.1 \times 1.105 = \mathbf{0.1105}$

Step 4: Calculate $k_4$ (Slope at end using $k_3$):
$x_0 + h = 0 + 0.1 = 0.1$
$y_0 + k_3 = 1 + 0.1105 = 1.1105$
$k_4 = h f(0.1, 1.1105) = 0.1 \times (0.1 + 1.1105) = 0.1 \times 1.2105 = \mathbf{0.12105}$

Step 5: Weighted Average to find $y(0.1)$:
$\Delta y = \frac{1}{6} [ k_1 + 2k_2 + 2k_3 + k_4 ]$
$\Delta y = \frac{1}{6} [ 0.1000 + 2(0.1100) + 2(0.1105) + 0.12105 ]$
$\Delta y = \frac{1}{6} [ 0.1000 + 0.2200 + 0.2210 + 0.12105 ] = \frac{0.66205}{6} \approx \mathbf{0.11034}$

$$y(0.1) = y_0 + \Delta y = 1 + 0.11034 = \mathbf{1.11034}$$

(Exact analytical solution $y = 2e^x - x - 1$ gives $y(0.1) = 2e^{0.1} - 0.1 - 1 = 1.11034$ — Matches to 5 decimal places!)

2. Picard's Method
⭐ CSJMU PYQs: 2024–25, 2023–24 (Integration method for IVP)

Converts the ODE $\frac{dy}{dx} = f(x,y)$ into an integral equation $y(x) = y_0 + \int_{x_0}^x f(t, y(t)) dt$, producing successive polynomial approximations.

📝 Solved Example: Picard's 3 Approximations for $\frac{dy}{dx} = x + y$, $y(0)=1$

Initial guess: $y^{(0)}(x) = 1$

First Approximation $y^{(1)}(x)$:
$y^{(1)}(x) = 1 + \int_0^x (t + 1) dt = 1 + \left[ \frac{t^2}{2} + t \right]_0^x = \mathbf{1 + x + \frac{x^2}{2}}$

Second Approximation $y^{(2)}(x)$:
$y^{(2)}(x) = 1 + \int_0^x \left[ t + \left(1 + t + \frac{t^2}{2}\right) \right] dt = 1 + \int_0^x \left( 1 + 2t + \frac{t^2}{2} \right) dt = \mathbf{1 + x + x^2 + \frac{x^3}{6}}$

Third Approximation $y^{(3)}(x)$:
$y^{(3)}(x) = 1 + \int_0^x \left( 1 + 2t + t^2 + \frac{t^3}{6} \right) dt = \mathbf{1 + x + x^2 + \frac{x^3}{3} + \frac{x^4}{24}}$

3. Euler vs Picard vs Runge-Kutta Comparison
Method Order of Global Error Requires Integration? Accuracy
Euler's Method $O(h)$ No (Simple evaluation) Low (Requires very small $h$)
Picard's Method Variable (Iterative) Yes (Analytical integral) High near $x_0$, fails for complex $f(x,y)$
Runge-Kutta 4th Order $O(h^4)$ No (Point evaluations only) Extremely High (Industry Standard)
