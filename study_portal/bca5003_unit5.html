1. TCP vs UDP Detailed Comparison
⭐ CSJMU PYQs: 2025–26, 2024–25, 2023–24, 2018 (Top repeated 10-mark question!)
Parameter TCP (Transmission Control Protocol) UDP (User Datagram Protocol)
Connection Type Connection-Oriented (3-Way Handshake) Connectionless (Fire-and-forget)
Reliability 100% Reliable (ACKs, Retransmissions, In-order sequencing) Unreliable (Best-effort delivery; packets can drop or arrive out-of-order)
Header Overhead 20 to 60 Bytes Fixed 8 Bytes (Extremely lightweight)
Flow & Congestion Control Yes (Sliding window & Slow Start / AIMD) None
Speed Slower due to handshake and ACKs Ultra-Fast (Minimal transmission latency)
Use Cases Web (HTTP/S), Email (SMTP), File Transfer (FTP) Live Voice/Video streaming (VoIP, Zoom), Online Gaming, DNS queries
2. TCP 3-Way Handshake (Connection Setup)
⭐ CSJMU PYQs: 2025–26, 2024–25, 2022–23, 2019 (Draw sequence diagram with SEQ & ACK)
TCP Connection Establishment: SYN → SYN-ACK → ACK
The 3 Steps Explained:
  1. SYN: Client chooses initial sequence number $x$ and sends a segment with SYN = 1 to request a connection.
  2. SYN + ACK: Server acknowledges client's request with ACK = x + 1, chooses its own sequence number $y$, and sends SYN = 1.
  3. ACK: Client confirms server's sequence number by sending ACK = y + 1. Connection is now ESTABLISHED and two-way data transfer begins!
3. Email System Architecture
⭐ CSJMU PYQs: 2024–25, 2022–23, 2019 (SMTP vs POP3 vs MIME)
  • SMTP (Simple Mail Transfer Protocol - Port 25): A push protocol used by the sender's client to transmit email to its mail server, and between mail servers. Transmits text in 7-bit ASCII only.
  • MIME (Multipurpose Internet Mail Extensions): An extension to SMTP that converts non-ASCII data (images, PDFs, audio, video, attachments) into 7-bit ASCII format for transmission across legacy SMTP servers.
  • POP3 (Post Office Protocol v3 - Port 110): A pull protocol that downloads emails from the mail server to the local client and usually deletes them from the server (offline model).
  • IMAP (Internet Message Access Protocol - Port 143): A more powerful pull protocol that synchronizes emails in real-time across multiple devices (phone, laptop) while keeping them stored on the mail server.
4. Cryptography: Symmetric vs Asymmetric
⭐ CSJMU PYQs: 2025–26, 2024–25, 2023–24, 2022–23 (Secret Key vs Public Key Encryption)
Feature Symmetric (Secret Key) Asymmetric (Public Key)
Keys Used Single Shared Secret Key for both encryption and decryption Key Pair: Public Key (encrypts) + Private Key (decrypts)
Encryption Speed Very Fast (Suitable for bulk data) Much Slower (Complex modular arithmetic)
Key Distribution Difficult (Must share secret securely) Easy (Public key can be shared openly)
Algorithms AES, DES, 3DES, Blowfish RSA, Diffie-Hellman, ECC
