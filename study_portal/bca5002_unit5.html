1. JSP Architecture & Lifecycle
⭐ CSJMU PYQs: 2024–25, 2023–24, 2022–23, 2019 (Why is there a delay on the first JSP request?)

JSP pages are not executed directly. Behind the scenes, the web container translates the .jsp file into an equivalent Java Servlet source file, compiles it into bytecode, and runs it as a standard servlet!

JSP Phases: Translation → Compilation → Loading → jspInit() → _jspService()
Why the First Request Experiences a Delay:
When a JSP page is accessed for the very first time, the server must dynamically parse and translate the HTML/JSP tags into Java source code and run the Java compiler (javac). Once compiled, subsequent requests execute the in-memory class immediately with zero delay. Modern enterprise apps solve this by pre-compiling JSP pages during deployment!
2. The 9 Implicit Objects in JSP
⭐ CSJMU PYQs: 2024–25, 2021 (Name implicit objects with underlying Java classes)

The JSP container automatically creates nine pre-defined objects available directly in any scriptlet or expression without declaring them:

Implicit Object Java Class / Interface Scope & Purpose
request HttpServletRequest Accesses query parameters, headers, and form inputs
response HttpServletResponse Sets HTTP headers, cookies, and redirects
out JspWriter Outputs character data directly to response stream
session HttpSession Maintains conversational state per user session
application ServletContext Global data shared across all users and pages in the web application
config ServletConfig Initialization parameters from web.xml
pageContext PageContext Provides central access to all scopes and attributes
page java.lang.Object Synonym for this (the generated servlet instance)
exception java.lang.Throwable Available only in designated error pages (isErrorPage="true")
3. JSP vs Servlet Comparison
Feature Java Servlet JSP (JavaServer Pages)
Primary Role Controller in MVC (Business logic, authentication, DB routing) View in MVC (UI rendering, display presentation)
Language Orientation Java code with embedded HTML strings inside out.println() HTML file with embedded Java tags/expressions
Modification Requires re-compilation and server restart/reload on changes Auto-recompiled by container upon saving file
Ease of Design Tedious for complex responsive layouts Easy for web designers familiar with HTML/CSS
Sum1To25.jsp (PYQ Solved) 
<%@ page language="java" contentType="text/html; charset=UTF-8" %>
<!DOCTYPE html>
<html>
<head><title>Sum of 1 to 25</title></head>
<body>
    <h2>Calculation in JSP Scriptlet</h2>
    <%
        int totalSum = 0;
        for (int i = 1; i <= 25; i++) {
            totalSum += i;
        }
    %>
    <p>The sum of numbers from 1 to 25 is: <strong><%= totalSum %></strong></p>
    <p>Formula Check [n(n+1)/2]: <strong><%= (25 * 26) / 2 %></strong></p>
</body>
</html>
