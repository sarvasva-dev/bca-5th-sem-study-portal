1. JSP Architecture & Lifecycle
⭐ CSJMU PYQs: 2024–25, 2022, 2019, 2017 (JSP lifecycle translation, jspInit vs _jspService)
🎯 Learning Objectives:
  • Understand how a .jsp page is translated and compiled into a Java Servlet.
  • Trace the three core lifecycle hooks: jspInit(), _jspService(), jspDestroy().
⚡ Essential Pass Content

What is JSP? Java Server Pages (JSP) is a server-side technology used to create dynamic, data-driven web pages. A JSP page is primarily an HTML template with embedded Java code tags.

The Under-the-Hood Secret of JSP:
"A JSP page IS a Servlet!" When a client first requests mypage.jsp:
  1. Translation: The JSP engine parses the page and translates it into a standard Java Servlet source file (mypage_jsp.java).
  2. Compilation: The Java compiler compiles the generated servlet into bytecode (mypage_jsp.class).
  3. Loading & Execution: The container loads the class into memory, invokes jspInit() once, and calls _jspService(req, res) for incoming requests.
2. JSP vs Servlets (MVC Pattern Role)
⭐ CSJMU PYQs: 2024–25, 2021, 2018 (When to use JSP vs Servlet in enterprise web apps)
⚡ Essential Pass Content
Feature Java Servlets Java Server Pages (JSP)
Core Nature HTML embedded inside Java code: out.println("<h1>" + data + "</h1>"); Java embedded inside HTML tags: <h1><%= data %></h1>
Primary Role (MVC) Controller: Handles business logic, authentication, and database routing View: Renders dynamic presentations, layouts, and user interfaces
Deployment Speed Code changes require explicit recompilation and web server redeployment Changes to .jsp files are recompiled automatically by the container at runtime
Design Separation Difficult for UI designers to read or edit Easy for frontend designers to style using HTML/CSS without knowing deep Java
3. Scripting Elements & The 9 Implicit Objects
⭐ CSJMU PYQs: 2025–26, 2023–24, 2020 (Name and describe all 9 implicit objects in detail)
⚡ Essential Pass Content
The 3 Primary JSP Scripting Elements:
  • Scriptlet (<% ... %>): Contains arbitrary Java statements placed directly inside the _jspService() method body.
  • Expression (<%= ... %>): Evaluates a Java expression and outputs it to the browser. Important: NEVER put a semicolon ; inside an expression!
  • Declaration (<%! ... %>): Declares class-level variables and methods placed outside the service method.
Implicit Object Underlying Java Class / Interface Core Functionality
request HttpServletRequest Accesses form parameters (getParameter()), headers, and cookies.
response HttpServletResponse Manages outgoing response headers, content types, and redirects.
out JspWriter Buffered output stream used to write content to client HTML page.
session HttpSession Stores user session state across multiple page visits.
application ServletContext Application-wide context shared across all users and pages in the webapp.
config ServletConfig Retrieves servlet initialization parameters.
pageContext PageContext Provides central access to all scopes (page, request, session, application).
page java.lang.Object (this) Represents the current translated servlet instance.
exception java.lang.Throwable Available strictly in designated error pages (isErrorPage="true").
Complete JSP Program (Sum of Numbers 1 to 25) 
<%@ page language="java" contentType="text/html; charset=UTF-8" pageEncoding="UTF-8"%>
<!DOCTYPE html>
<html>
<head>
    <title>JSP Calculation Demo</title>
</head>
<body>
    <h2>Sum of Integers from 1 to 25</h2>

    <%! 
        // JSP Declaration: class-level helper method
        int computeSum(int n) {
            return (n * (n + 1)) / 2; // Mathematical summation formula
        }
    %>

    <%
        // JSP Scriptlet: procedural calculation inside service()
        int total = computeSum(25);
    %>

    <p>The calculated sum is: <strong><%= total %></strong></p>
    <p>Server Time: <%= new java.util.Date() %></p>
</body>
</html>
