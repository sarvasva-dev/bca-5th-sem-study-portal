⚡ Network Devices by OSI Layer
OSI Layer Connecting Device Addressing Used Primary Function
Layer 1 (Physical) Repeater / Hub None (Raw Bits) Regenerates signal; broadcasts bits to all ports
Layer 2 (Data Link) Bridge / Switch MAC Address (48-bit) Filters & forwards frames; learns MAC addresses in CAM table
Layer 3 (Network) Router IP Address (32/128-bit) Routes packets across different subnets; breaks broadcast domains
Layers 4–7 (Upper) Gateway Port / Application Data Translates between completely different network protocol architectures
1. Hub vs Switch: Complete Comparison
⭐ CSJMU PYQs: 2025–26, 2024–25, 2023–24, 2021, 2019 (Asked almost every year!)
Parameter Hub (Dumb Device) Switch (Intelligent Device)
Operating Layer Layer 1 (Physical Layer) Layer 2 (Data Link Layer)
Transmission Mode Broadcasts incoming data to all connected ports Unicasts data directly to destination port via MAC table
Collision Domains Single shared collision domain for all ports Each port has its own dedicated collision domain
Transmission Duplex Half-duplex only (collisions can happen) Full-duplex supported (simultaneous send/receive)
Addressing Does not understand MAC or IP Learns and stores 48-bit MAC addresses
2. IPv4 Classful Addressing & Subnet Masks
⭐ CSJMU PYQs: 2024–25, 2021, 2018 (Identify IP class and calculate network/host IDs)

IPv4 addresses are 32 bits (4 bytes) long, written as four decimal octets separated by dots (e.g., 192.168.1.1).

Special Reserved IPs:
• 127.0.0.1: Loopback address (testing local TCP/IP stack).
• Host ID all 0s: Represents the Network ID.
• Host ID all 1s: Represents the Directed Broadcast Address.
3. Framing: Bit Stuffing (HDLC)
⭐ CSJMU PYQs: 2024–25, 2017 (Perform bit stuffing on a given stream)

Rule of Bit Stuffing: Delimiter flag is 01111110 (six consecutive 1s). Whenever the transmitter's hardware sees five consecutive 1s in the user data stream, it automatically inserts (stuffs) a 0 bit immediately after them, preventing premature end-of-frame recognition.

Example:
Original Data: 01101111111001
After seeing five 1s: 011011111011001 (A 0 is stuffed!)
Receiver automatically strips the stuffed 0 after five consecutive 1s to restore original data.
