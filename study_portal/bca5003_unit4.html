1. Network Connecting Devices & Domains
⭐ CSJMU PYQs: 2024–25, 2022, 2020, 2017 (Hub vs Switch, Collision vs Broadcast domain differences)
⚡ Essential Pass Content
Device OSI Layer Collision Domain Behavior Broadcast Domain Behavior
Repeater / Hub Layer 1 (Physical) Single shared collision domain (all ports collide) Single broadcast domain (blindly repeats to all)
Bridge / Switch Layer 2 (Data Link) Breaks collision domains: Every port is a separate, private collision domain Single broadcast domain: Floods broadcasts (FF:FF:FF:FF:FF:FF) across all ports
Router Layer 3 (Network) Separate collision domain per port Breaks broadcast domains: Does NOT forward broadcast packets across subnets
Gateway All Layers (1 to 7) Translates incompatible protocol suites (e.g. SNA to TCP/IP) Translates network architectures
Domain Definitions:
  • Collision Domain: A network segment where packet collisions can occur when two devices transmit simultaneously. Switches eliminate collisions by giving every port its own dedicated micro-segment!
  • Broadcast Domain: The set of all network devices that receive an Ethernet broadcast frame. Only Routers contain and isolate broadcast domains.
2. Data Link Framing & Bit Stuffing
⭐ CSJMU PYQs: 2025–26, 2023–24, 2021, 2018 (Bit stuffing algorithm & worked problem)
⚡ Essential Pass Content

Framing breaks the raw physical layer bitstream into discrete logical units called Frames so the receiver can detect the start and end of every message.

The Bit Stuffing Rule (HDLC Protocol):
Frames begin and end with a special flag pattern: $01111110$ (six consecutive 1s).
To prevent the user's data from accidentally containing this flag sequence, the sender's hardware monitors the bitstream: "Whenever the transmitter encounters five consecutive 1s ($11111$) in the payload data, it automatically injects an extra 0 after the fifth 1."
The receiver detects five consecutive 1s followed by a 0, and automatically removes (de-stuffs) that zero!
📝 Worked Exam Numerical:
Original Data: 011011111110111110010
1. Find 5 consecutive 1s: 011011111[0]11011111[0]0010
2. Framed Output with Flags:
[01111110] 01101111101101111100010 [01111110]
3. IPv4 Classful Addressing & Subnetting Math
⭐ CSJMU PYQs: 2024–25, 2021, 2019 (Address classes, default subnet masks, and subnet calculations)

An IPv4 address is a 32-bit identifier written in dotted-decimal notation ($4 \times 8$-bit octets from $0$ to $255$).

Class Leading Bits 1st Octet Range Default Subnet Mask Net ID / Host ID Split Max Usable Hosts / Network
Class A 0 $1 - 126$ ($127$ reserved for loopback) $255.0.0.0$ (/8) $8 \text{ bits Net} \mid 24 \text{ bits Host}$ $2^{24} - 2 = \mathbf{16,777,214}$
Class B 10 $128 - 191$ $255.255.0.0$ (/16) $16 \text{ bits Net} \mid 16 \text{ bits Host}$ $2^{16} - 2 = \mathbf{65,534}$
Class C 110 $192 - 223$ $255.255.255.0$ (/24) $24 \text{ bits Net} \mid 8 \text{ bits Host}$ $2^8 - 2 = \mathbf{254}$
Class D 1110 $224 - 239$ None Multicast Groups N/A
Class E 1111 $240 - 255$ None Experimental / Research N/A
📝 Master Solved University Subnetting Numerical:
An organization is assigned the Class C network block $192.168.10.0/26$. Determine:
  • Subnet Mask
  • Number of Subnets created
  • Number of Usable Hosts per subnet
  • First Subnet's Usable Host Range and Broadcast Address
1. Subnet Mask (/26 prefix):
$26$ consecutive binary 1s: $11111111.11111111.11111111.11000000_2$
Last octet: $128 + 64 = 192 \implies \mathbf{255.255.255.192}$.
2. Number of Subnets:
Default Class C uses 24 network bits. Here 2 additional bits are borrowed for subnetting ($26 - 24 = 2$ bits):
$$\text{Number of Subnets} = 2^2 = \mathbf{4 \text{ Subnets}}$$
3. Number of Usable Hosts per Subnet:
Remaining host bits = $32 - 26 = 6$ bits.
Subtract 2 addresses (Network ID and Broadcast ID):
$$\text{Usable Hosts} = 2^6 - 2 = 64 - 2 = \mathbf{62 \text{ Hosts / Subnet}}$$
4. First Subnet Range ($192.168.10.0/26$):
• Network ID: $192.168.10.0$
• First Usable Host: $192.168.10.1$
• Last Usable Host: $192.168.10.62$
• Directed Broadcast Address: $192.168.10.63$
